Experiment I Supplement: Dense-SVD Vector Retrieval Baseline
Motivation: reviewer noted TF-IDF is a weak vector baseline; standard RAG uses dense embeddings + FAISS.
What we did: TruncatedSVD on TF-IDF matrix -> dense vectors (64d/128d/256d) -> cosine similarity retrieval.
This is the strongest dense (non-neural) vector baseline deployable in the closed-network environment.
FAISS note: FAISS is an ANN index, not an embedding method. Same vectors = identical rankings. FAISS matters at 100K+ scale, not 1,237 episodes.

Key Findings
Dense-SVD outperforms TF-IDF by +6.0pp Top-1 (25.2% vs 19.2%) — reviewer correct that sparse TF-IDF is not the strongest vector baseline.
Dense-SVD competitive with signature-compiled at Top-1 (25.2% vs 23.0%), but lags at Top-10 (64.7% vs 75.4%).
LLM-compiled still dominates by +7.8pp Top-1 (33.0% vs 25.2%) — the semantic gap persists even with dense latent vectors.
64d outperforms 128d/256d — TF-IDF semantic signal saturates quickly; more dimensions add noise.
Core claim strengthened: the bottleneck is semantic quality of what is indexed, not the retrieval data structure (hash vs dense vs graph).
FAISS is orthogonal: would return identical rankings on same vectors. The missing piece is a neural encoder, not a faster index.
